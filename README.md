## 同样是8核32G，价格为什么差出一倍

三个原因：CPU是否独享、架构和代数、计费周期。

差价的大头在共享和独享。经济型e实例是共享CPU规格，会有因CPU共享调度带来的性能波动，官方也明确这类实例如果波动影响业务，可以切换到独享型。所以e实例适合测试环境、内部工具、静态站点这类对稳定性要求不高的活儿。要是这台机器要跑MySQL加Redis扛正式业务，别为了省钱选它——e实例和g7一年差3400多，省下来的钱可能不够填一次性能故障的坑。

架构是第二个变量。AMD的g7a比Intel系便宜近两千元一年，常规业务够用；ARM的g6r更便宜，但前提是你的软件栈能在ARM上正常跑，比如PHP、Go、大部分开源组件没问题，某些闭源商业软件就得先确认。

第三个变量是时长，这个放后面优惠部分细说。
